# rosbars — превью сайта (редизайн)

Демо-версия сайта АНО ИЦ «Независимая Экспертиза» (rosbars.ru) для оценки заказчиком.

- Статический сайт, GitHub Pages.
- 14 страниц: главная, каталог услуг, 8 страниц видов экспертиз, о центре, кейсы, контакты, политика.
- Навигация, хлебные крошки, FAQ (Schema.org), галерея сертификатов, форма заявки, виртуальный ИИ-консультант.
- Тексты — под SEO/GEO; цены «от» из открытых источников (ознакомительные).
- Сборка: `node build.js` (без зависимостей). Правки контента — в `build.js`.

Превью помечено `noindex` — при переносе на боевой домен rosbars.ru убрать мета-тег robots и заменить пути/каноникал.
